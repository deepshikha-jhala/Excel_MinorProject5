# Excel_MinorProject5
📊 Sales Operations Analytics — Excel Minor Project

📌 Project Overview

This project analyzes sales operations data for a fictional multi-category retailer operating across 6 Indian cities.
The objective was to work with raw business data and apply practical Excel techniques used in real-world Data Analytics and Business Analytics workflows — from data lookup and cleaning to aggregation, pivot analysis, and advanced calculations.

This project was completed as an Excel Minor Project as part of my Data Analytics / Data Science learning journey.


🛠️ Skills & Techniques

- VLOOKUP, INDEX + MATCH
- SUMIFS, COUNTIFS, AVERAGEIFS
- Data Cleaning & Validation
- Pivot Tables & Filters
- Ranking & Cumulative Analysis
- Multi-sheet Data Analysis


📈 Key Analysis

- Sales and revenue analysis
- Sales representative performance
- Target vs. actual performance
- Product and category analysis
- Data-quality checks
- Top-N and cumulative analysis


📌 Learning Outcomes

Through this project, I strengthened my ability to:

Work with data → Clean data → Analyze data → Find patterns → Generate business insights

More specifically, I gained practical experience in:

- Handling structured business datasets
- Connecting information across multiple Excel sheets
- Writing advanced Excel formulas
- Building analytical logic for business questions
- Using Pivot Tables for summarization
- Performing data-quality checks
- Thinking from a business-question perspective rather than just calculating numbers
